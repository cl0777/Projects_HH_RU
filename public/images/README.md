# Images Directory

## Required Images

### Video Poster Image
- **File**: `logistics-hero-poster.jpg`
- **Format**: JPG
- **Resolution**: 1920x1080 (Full HD)
- **Content**: Static image representing the video content
- **Purpose**: Shows while video is loading
- **File Size**: Keep under 500KB

### Recommended Content for Poster
- Logistics warehouse or shipping facility
- Trucks or containers
- Modern logistics technology
- Global shipping imagery
- Professional logistics environment

## Fallback
If no poster image is provided, the video will show a black screen while loading.
