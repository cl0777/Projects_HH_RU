# Video Background Files

## Required Video Files

Place your logistics-themed video files in this directory:

### Primary Video (Required)
- **File**: `logistics-hero.mp4`
- **Format**: MP4 (H.264 codec)
- **Resolution**: 1920x1080 (Full HD) or higher
- **Duration**: 10-30 seconds (will loop)
- **Content**: Logistics/shipping themed (trucks, containers, warehouses, etc.)
- **File Size**: Keep under 10MB for web performance

### Fallback Video (Optional)
- **File**: `logistics-hero.webm`
- **Format**: WebM (VP9 codec)
- **Resolution**: 1920x1080 (Full HD) or higher
- **Duration**: 10-30 seconds (will loop)
- **Content**: Same as MP4 version
- **File Size**: Keep under 8MB for web performance

## Video Specifications

### Recommended Content
- Moving trucks on highways
- Container ships at ports
- Warehouse operations
- Cargo planes taking off
- Global shipping routes
- Modern logistics facilities

### Technical Requirements
- **Aspect Ratio**: 16:9
- **Frame Rate**: 24-30 fps
- **Bitrate**: 2-5 Mbps
- **Audio**: None (muted for autoplay)
- **Loop**: Seamless loop (no visible cuts)

### Performance Tips
- Use video compression tools to optimize file size
- Consider using a video CDN for better loading times
- Test on mobile devices for performance
- Provide fallback gradient background if video fails to load

## Fallback
If no video files are provided, the hero section will display a gradient background with animated elements.
